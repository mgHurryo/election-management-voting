## Before Development

### Must

- Read [RULES.md](RULES.md) before making any changes to the project.
- Personal files and configurations, such as IDE settings, local environment files, and personal agent configurations, must be strictly excluded from the repository.
- Do not commit secrets, credentials, API keys, tokens, passwords, or other sensitive information.
- Make sure your changes follow the branch, commit, and pull request rules defined in [RULES.md](RULES.md).

### Optional

- Read the documentation under [`docs/`](docs/) to understand the project background and design.
- Review the existing project structure and implementation before making changes.
- Verify that the project can build and run successfully in your local environment.
- Run the existing tests before starting development.
- Configure your preferred IDE, development tools, and coding agents locally.
- If you use AI coding tools or agents, review all generated changes before committing them.
