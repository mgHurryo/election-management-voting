# 未来工作 · Future Work（Backlog）

[English](../../FUTURE.md) / 简体中文

---
> 关联需求：SRS v0.1（[中文](../requirements/REQUIREMENTS_CN.md) / [English](../../REQUIREMENTS.md)）
> 最后更新：2026-09-26

本文件汇总所有**不在 v0.1 MVP 基线内**的内容，分**三类**，请勿混淆：

1. **未来版本可能纳入的能力**——本版不做，但**可能在未来版本出现**（FW-01 ~ FW-08）；
2. **待未来版本定义的规则与指标**——原 v0.1 中尚未拍板、现统一推迟的项（FW-10 ~ FW-14）；
3. **永久排除项**——**不会在未来版本出现**，不属于 Future Work（FW-09）。

需求文档只保留已拍板的 v0.1 需求；凡是未确定或本版不做的，一律记在这里，作为后续迭代的 backlog。

> **只有第 1、2 类是真正的 Future Work**，未来可能由组长决定纳入某个版本。
> **第 3 类是原则性排除**，不应被理解为「以后再做」；除非项目范围发生根本性的重新决策，否则不得纳入。

> **变更纪律**：第 1、2 类条目要被纳入某个版本，须由组长决定，把它从本文件迁回需求文档、更新需求文档版本号、记录变更原因，并同步检查相关 FR / BR / AC 的一致性（中英两版同步）。第 3 类不适用此流程。

## 1. 未来版本可能纳入的能力（本版不做）

这些能力本版不做，但**属于候选的未来工作**，未来版本可能纳入。

| ID | 条目 | 说明 |
| --- | --- | --- |
| FW-01 | 多选 / 评分制 / 评委评分 | v0.1 只做单选 |
| FW-02 | 多职位选举 | 一场选举同时选主席、副主席、秘书等多个职位；v0.1 一场只选一个职位 |
| FW-03 | 复杂投票权重 | 如按持股比例、分组加权 |
| FW-04 | 多轮 / 大型赛事式选拔流程 | 分区、分组、多阶段 |
| FW-05 | 通用选举流程引擎 | 「通用模板 + 个性化模板」抽象，覆盖所有选举制度 |
| FW-06 | 独立治理角色 | 审计员 / 系统管理员 / 选举委员会的独立账号与权限；v0.1 由管理员兼任 |
| FW-07 | 实时投票率展示 | 投票进行中的实时投票率 |
| FW-08 | 运营与后台能力 | 投票回执、审计日志查询、结果导出、邮件通知、后台账号管理 |

## 2. 待未来版本定义的规则与指标（原 v0.1 未确认项）

| ID | 条目 | v0.1 现状 | 待定义内容 |
| --- | --- | --- | --- |
| FW-10 | 平票处理 | 仅「得票最高者当选」，不处理平票 | 平票的处理方式（管理员手动重投或系统自动裁决）与自动晋级机制 |
| FW-11 | 量化性能指标 | 不设量化性能验收门槛 | 并发选民数、投票提交与计票的响应时间指标，待技术验证后确定 |
| FW-12 | 其他选举结束条件 | 仅以「投票结束时间」为结束条件 | 「达到结束票数即自动关闭」等其他结束条件 |
| FW-13 | 结果公开范围 | 管理员发布结果、选民查看已公开结果 | 更细的分角色可见性策略 |
| FW-14 | 候选人照片规则 | 照片为可选 | 是否必填及缺省处理 |
