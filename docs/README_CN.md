# 选举管理与投票系统

[English](../README.md) / 简体中文

本项目是 **COMP 3500SEF** 课程的小组项目。

## 开发前准备

### 必须

- 在对项目进行任何修改之前，阅读 [RULES.md](../RULES.md)。
- 个人文件和个人配置必须严格排除在仓库之外，例如 IDE 配置、本地环境文件以及个人 Agent 配置。
- 不得提交 Secret、凭据、API Key、Token、密码或其他敏感信息。
- 所有修改必须遵循 [RULES.md](../RULES.md) 中定义的分支、Commit 和 Pull Request 规范。

### 可选

- 阅读 [`docs/`](./) 目录中的项目文档，了解项目背景与设计。
- 修改代码前先了解现有项目结构和实现。
- 开发前确认项目能够在本地环境正常构建和运行。
- 开发前运行已有测试，确认当前基线状态正常。
- 根据个人习惯配置 IDE、开发工具和 Coding Agent。
- 如果使用 AI 编程工具或 Agent，应在提交前人工检查其生成的所有修改。
